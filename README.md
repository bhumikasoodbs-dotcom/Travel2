# WanderMore Travel Landing Page

A responsive, single-page travel website concept for Europe, USA and Canada packages.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — itinerary enquiry modal and demo form interaction
- `assets/design-mockup.png` — generated visual design reference

## Run
Open `index.html` in any modern browser. No build tools or server are required.

## Notes
The package prices, phone number and email address are demo content. Replace them with your actual business details before publishing.
